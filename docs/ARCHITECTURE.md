## Системный обзор

Проект сочетает frontend на Next.js (React) и слой данных через Prisma. Код и документация находятся в `app/frontend/`.

<div align="center">

| **Домен**   | **Технология**                 | **Назначение**                                       |
| :---------- | :----------------------------- | :--------------------------------------------------- |
| Frontend    | React + Next.js + TypeScript   | UI и пользовательские сценарии                       |
| База данных | PostgreSQL + Prisma            | Хранение данных, миграции                            |
| Миграции    | Prisma Migrate                 | Управление схемой БД                                 |

</div>

---

## Ключевые потоки

1. Пользователь просматривает подборку фильмов и открывает страницу медиаконтента.
2. Next.js сервер/Server Action возвращает метаданные фильма, клиент инициализирует плеер.
3. Прогресс просмотра и взаимодействия отправляются на сервер для сохранения.
4. Рекомендации и списки формируются на основе данных в базе через Prisma.

## Архитектурные границы и слои

В проекте нет отдельного монолитного backend сервиса: серверная логика реализована внутри Next.js (Server Actions / API routes) и взаимодействует с Prisma.

<div align="center">

| **Слой**     | **Папка (пример)**   | **Назначение**                                                 |
| :----------- | :------------------ | :------------------------------------------------------------- |
| API / Actions| `app/frontend/src/app/` | API routes, Server Actions, обработка запросов                 |
| Data access  | `app/frontend/prisma/` | Prisma schema, клиент, миграции                                |
| UI / Client  | `app/frontend/src/`   | React компоненты, страницы, client-side логика                 |

</div>

## Frontend границы

Подход: модульные компоненты, разделение на `features`, `entities`, `shared`.

<div align="center">

| **Директория** | **Назначение**                               |
| :------------- | :------------------------------------------- |
| `app/`         | Роуты, инициализация, провайдеры приложения  |
| `pages/`       | Страницы пользовательских сценариев          |
| `widgets/`     | Крупные композиционные UI-блоки              |
| `features/`    | Изолированные пользовательские действия      |
| `entities/`    | Сущности предметной области                  |
| `shared/`      | Переиспользуемые модули (`api`, `ui`, `lib`) |

</div>

## Интеграции

<div align="center">

| **Категория**  | **Технология**    | **Назначение**                           |
| :------------- | :---------------- | :--------------------------------------- |
| HTTP-запросы   | Axios / fetch     | Взаимодействие frontend ↔ server         |
