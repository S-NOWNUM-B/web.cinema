## Системный обзор

Проект построен на базе **Next.js 16** с использованием App Router. Это позволяет объединить клиентский и серверный код в одном приложении, обеспечивая бесшовную передачу данных и высокую скорость загрузки страниц.

<div align="center">

| **Домен**   | **Технология**                 | **Назначение**                                       |
| :---------- | :----------------------------- | :--------------------------------------------------- |
| Frontend    | React 19 + Tailwind 4          | UI, плеер, анимации (Framer Motion)                  |
| Server      | Next.js Server Actions / API   | Бизнес-логика, SSR, аутентификация                   |
| База данных | PostgreSQL 16 + Prisma 7       | Хранение данных (фильмы, пользователи, прогресс)     |
| Хранилище   | AWS S3 / Local Storage         | Хранение видеофайлов и изображений                   |

</div>

## Ключевые потоки

### Просмотр фильма

1. Пользователь выбирает фильм на главной странице.
2. Next.js выполняет Server-side Rendering для получения метаданных фильма через Prisma.
3. Клиентский компонент `VideoPlayer` инициализируется и начинает стриминг контента.
4. Каждые 30 секунд прогресс просмотра отправляется на сервер через Server Action для сохранения в БД.

### Поиск и фильтрация

1. Пользователь вводит запрос в строку поиска.
2. Next.js API Route выполняет полнотекстовый поиск в PostgreSQL.
3. Результаты отображаются мгновенно с использованием `useOptimistic` для плавности интерфейса.

## Frontend компоненты

Мы используем модульный подход к компонентам:

- **UI (Shared):** Базовые элементы из Shadcn UI (кнопки, инпуты, модальные окна).
- **Features:** Сложные блоки, такие как `VideoPlayer`, `MovieCard`, `HeroSection`.
- **Layouts:** Общие обертки для страниц (Header, Footer, Sidebar).
